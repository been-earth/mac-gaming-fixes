# аудиоустройства

wine использует устройства macos по умолчанию. эта карточка выбирает их без похода в системные настройки и не даёт bluetooth-гарнитуре незаметно стать микрофоном.

## что делает

- выбирает системное устройство вывода
- выбирает системное устройство ввода
- задаёт громкость входа выбранного микрофона

## как работает

все три — свойства coreaudio: два у системного объекта, одно у устройства. списки обновляются, когда устройство подключается или меняется устройство по умолчанию.

```c CoreAudio
kAudioHardwarePropertyDefaultOutputDevice   // вывод
kAudioHardwarePropertyDefaultInputDevice    // микрофон
kAudioDevicePropertyVolumeScalar            // громкость входа, область input
```

## ловушка bluetooth

когда подключается bluetooth-гарнитура, macos часто делает её микрофон входом по умолчанию. первое приложение, которое откроет этот микрофон, переводит гарнитуру в профиль звонков 16 кгц моно, и звук игры становится телефонным. карточка предупреждает, если выбранный вход — bluetooth-устройство.

## ограничения

- у некоторых устройств нет программной громкости входа. для них ползунок скрыт.
- macos может снова переключить устройства при повторном подключении гарнитуры. карточка покажет изменение, но не отменит его.
